# Hospital-patient-analysis-project
Hospital Data Analysis | Microsoft Excel

📌 Project Overview

This project focuses on analyzing hospital patient data using Microsoft Excel. The objective is to understand patient demographics, admission trends, hospital billing, and healthcare service patterns through data analysis and interactive dashboards.

🎯 Project Objectives

- Analyze total patient admissions.
- Understand patient distribution by age group.
- Identify admission trends over time.
- Analyze hospital billing and financial performance.
- Compare patient admissions across different categories.
- Generate meaningful insights using Excel dashboards.

🛠️ Tools & Technologies

- Microsoft Excel

- Slicers
- Data Cleaning
- Data Visualization
